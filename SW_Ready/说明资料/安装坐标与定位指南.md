# 安装坐标与定位指南

对应`SW_Ready/装配体/无头Go2传感器安装总装.SLDASM`。从保存后的实际SW组件变换提取，共22个顶层组件和3个相机子组件。没有修改模型几何、安装位置和配合结构。

## 1. 坐标系原点及方向

机器人基坐标系记为B，取当前总装原点，沿用Go2 URDF基准，是右手系：**X向机器人前方、Y向机器人左侧、Z向上**。左右从机器人自身视角判断。

此原点不是重心、机身包围盒中心、脚底地面或相机中心。base整体未装入不影响基准保留。禁止将每个零件按包围盒居中后再套用本表。

用当前模型四个髋关节零件的局部原点复核B：

| 位置 | X / Y / Z（mm） |
|---|---|
| 前左 | 193.4 / 46.5 / 0 |
| 前右 | 193.4 / -46.5 / 0 |
| 后左 | -193.4 / 46.5 / 0 |
| 后右 | -193.4 / -46.5 / 0 |

四点平均为(0,0,0)。后侧髋原点中点指向前侧中点为+X，右侧中点指向左侧中点为+Y，X×Y为+Z。这里指模型局部原点，不应把电机外观圆面中心或实机螺钉中心未经核实当成这些点。

腿部为原URDF零关节角参考布置，**不代表实机站立姿态**。关节姿态改变后，腿部变换需更新，表中坐标不能直接用作实机运动指令。

## 2. 平移、旋转的统一定义

平移用毫米，角度用度。采用列向量及右手旋转：

```text
p_A = R_A_B p_B + t_A_B
T_A_B = [ R_A_B  t_A_B ]
        [ 0 0 0     1   ]
R_A_B = Rz(yaw) Ry(pitch) Rx(roll)
T_B_子 = T_B_父 T_父_子
T_父_子 = inverse(T_B_父) T_B_子
```

T_A_B将B系点转换到A系；t是B原点在A系的位置。RPY对应依次绕固定参考系X、Y、Z轴的外禀旋转，不能任意交换顺序。四元数采用**qx,qy,qz,qw**。欧拉角有等价表示，优先使用完整矩阵或四元数。

文档表中是零件局部原点的位置，不是几何中心。矩阵不需再乘一次URDF、DAE或已有网格场景变换。STL已经是毫米，不能重复缩放1000倍。

## 4. 各类零件的局部原点

- 相机支架与后盖一体件在机器人全局坐标中绘制，以单位变换装入。它的原点与B一致，(0,0,0)不表示实体位于机器人中心，禁止再叠加相机位姿。

- 雷达支撑件保留源原点，旋转为单位矩阵，再按全局表平移。
- 相机、主壳及前框共用相机机械系C：局部X沿宽度，朝机器人+Y；局部Y沿高度，朝机器人+Z；局部Z朝相机前方，朝机器人+X。C原点位于本CAD前面Zc=0及宽高基准线的交点，不是几何中心。
- `机身与原厂雷达一体模型.SLDPRT`是未装入的可选参考，不包含在26组件表内。它保留源视觉模型原点；本项目源基准对应单位变换，不重新居中。加入该整体后的干涉尚未验证。

## 5. 深度图光学坐标系

深度光学系记为D：+Xd图像向右，+Yd图像向下，+Zd成像前方。装入机器人后分别朝-Y、-Z、+X。

**光学原点在B系为(220,0,100)mm，即(22,0,10)cm。** 取整的是这个点，不是相机外壳中心。

厂家名义关系：深度原点为左红外中心，横向距三脚架孔中心线17.5mm，深度基准位于前玻璃后4.2mm。本CAD机械系中光学原点为(17.5,0,-4.2)mm。光学轴与机械轴还相差绕机械Z轴180°，不能只加平移。

```text
机械坐标 → 机器人：
Xb = Zc + 224.2
Yb = Xc - 17.5
Zb = Yc + 100
T_B_C =
[ 0.000000000   0.000000000   1.000000000   224.200000000]
[ 1.000000000   0.000000000   0.000000000  -17.500000000]
[ 0.000000000   1.000000000   0.000000000   100.000000000]
[ 0.000000000   0.000000000   0.000000000   1.000000000]

光学坐标 → 机器人：
Xb = Zd + 220
Yb = -Xd
Zb = -Yd + 100
T_B_D =
[ 0.000000000   0.000000000   1.000000000   220.000000000]
[-1.000000000   0.000000000   0.000000000   0.000000000]
[ 0.000000000  -1.000000000   0.000000000   100.000000000]
[ 0.000000000   0.000000000   0.000000000   1.000000000]
```

机械原点为(224.2,-17.5,100)mm；包围盒几何中心约(211.675,-17.452403,99.999979)mm。这些点不是光学原点。深度反投影得到的光学点应使用T_B_D，不是T_B_C。

程序若用米，平移除以1000，旋转不变；光学平移为(0.22,0,0.10)m。RGB/IMU外参不能用这组深度外参代替。此为厂家名义机械布置，不替代实机外参标定。来源：[RealSense D400手册，第89、92页](https://realsenseai.com/wp-content/uploads/2025/08/Intel-RealSense-D400-Series-Datasheet-August-2025.pdf)。

## 7. 在新装配中复现的步骤

1. 建立毫米制B系，按第1节核对原点与方向；不能改用地面或包围盒中心。
2. 保留各零件局部坐标，按全局表装入机器人零件及雷达安装件。同文件多个实例各有坐标，分别取对应行。
3. 相机支架与后盖一体件以单位变换装入，检查底面与中间件两孔。
4. 直接插入`带保护壳的深度相机.SLDASM`，仅对子装配施加T_B_C，内部3个组件仍用单位变换。若拆开逐件插入，则每个都施加T_B_C；两种方式不能同时做，防止重复变换。
5. 检查相机后面与支架、45mm孔距、孔轴方向、壳体四孔同轴及支架避让。
6. 验算机械局部(17.5,0,-4.2)经T_B_C后为(220,0,100)。光学+Z应朝机器人+X，光学+X朝机器人-Y，光学+Y朝机器人-Z。
7. 根据实物公差、紧固件、线缆和实机标定验收。不能把外参四舍五入到整厘米替代标定。

当前SW采用固定坐标放置，未新增孔同轴或面重合配合。坐标表描述安装姿态，不等于已完成机械约束和实机验证。

## 8. 文件格式与读取示例

```python
import csv
import numpy as np
rows = list(csv.DictReader(open('全部组件_机器人坐标.csv', encoding='utf-8-sig')))
row = next(r for r in rows if r['组件'].endswith('/D435i深度相机-1'))
R = np.array([[float(row[f'R{i}{j}']) for j in range(1, 4)] for i in range(1, 4)])
t = np.array([float(row[k]) for k in ['tx_mm', 'ty_mm', 'tz_mm']])
assert np.allclose(R @ np.array([17.5, 0, -4.2]) + t, [220, 0, 100])
```

原始TSV列为组件、文件、父组件、a0…a15。前9数是SW按列存储的3×3旋转；a9…a11为米制平移，a12为缩放1，末3项保留。它不是常规行主序4×4矩阵。建议使用JSON中的常规4×4矩阵或CSV的R11…R33。
