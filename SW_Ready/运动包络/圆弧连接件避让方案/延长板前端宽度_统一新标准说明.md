# 上方雷达延长板：统一新余量标准后的前端宽度

本次仅量测，不修改模型。原前端最宽52mm、颈部约40mm，后部宽板最大134mm；位置、高度均保持原装配。

采用与中间件此次宽度复核相同的标准：±48°和±60°采样包络各自外扩3mm，在此安全参考之外还需至少2mm CAD间距。不能把此前原包络中心距离下的26mm建议直接沿用到这个更严格标准。

裁窄范围必须从机器人X=160mm起，覆盖颈部和最外端，直到原端部X≈222.078mm（长度约62.1mm）；Y=0居中保留指定宽度，X<160mm后部不变。不移动零件。仅改最外端或从X=170mm才开始收窄，不足以满足新标准。

按原STEP实际中面提取精确XY轮廓，按候选宽度裁剪；对安全参考包络逐1mm的Z层生成准确XY多边形区，用平面距离与Z向区间距离的平方和计算完整三维最小距离。板厚Z=45.656…47.656mm保持原值。数据见“延长板前端宽度_全三维新标准.json”。

| 前段宽度 | ±48°最小参考间距 | ±60°最小参考间距 | 两种范围均≥2mm |
|---|---:|---:|---|
| 24mm | 约2.75mm | 约1.26mm | 否 |
| 23mm | 约3.22mm | 约1.53mm | 否 |
| 22mm | 约3.69mm | 约1.89mm | 否 |
| 21mm | 约4.16mm | 约2.31mm | 是 |
| 20mm | 约4.41mm | 约2.75mm | 是 |

因此若按整数毫米落图，当前检查中最大推荐前段宽度为21mm；不能套用中间件的24mm或22mm。52mm最外端两侧各减15.5mm；约40mm颈部两侧各减约9.5mm。旧两侧安装孔会被影响，需要配套重布孔；实际过渡形状、孔边距和强度应在设计时复核，不能把裁宽计算当作成品图纸。

该标准是基于1°/1mm采样及3mm参考扩张的CAD检查，仍不构成实机连续运动或制造误差的严格保证。原模型、STEP及装配本次均未更改。
